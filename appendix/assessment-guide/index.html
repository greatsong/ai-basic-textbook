문항 구조

섹션 제목: “문항 구조”

A유형 — 개념 설명 (4문항)

“~의 역할을 설명하시오”, “~의 특징을 비교하시오”처럼 핵심 개념을 정확하게 서술하는 문항입니다.

  • A1: 활성화함수의 역할 + ReLU vs Sigmoid 비교
  • A2: 손실함수의 역할 (학습과 최적화의 관계)
  • A3: 경사하강법의 원리 (기울기, 학습률, 최솟값)
  • A4: 활성화함수 3종 이상 + 각 특징

B유형 — 상황 적용 (2문항)

“만약 ~라면 어떻게 되는가?”처럼 배운 개념을 새로운 상황에 적용하는 문항입니다.

  • B1: 단층 퍼셉트론이 XOR을 못 푸는 이유 (좌표평면 활용)
  • B2: 활성화함수를 전부 제거하면 생기는 문제 (XOR 예시)

C유형 — 종합 분석 (1문항)

여러 개념을 인과적으로 연결하여 분석하는 문항입니다.

  • C1: ChatGPT가 환각을 일으키는 구조적 원인
  • (토큰화, 확률적 예측, 손실함수, 학습 데이터를 연결하여 설명)

배점과 환산

섹션 제목: “배점과 환산”
  • 7문항의 원배점 합계는 80점입니다.
  • 원점수에 0.5를 곱해 40점 만점으로 환산합니다.
  • 예: 원점수 64점이면 → 64 x 0.5 = 32점

채점 기준 요약

섹션 제목: “채점 기준 요약”

A/B유형 (각 10점):

수준점수기준
상9~10핵심 개념 정확 + 구체적 예시나 비유 포함
중6~8대체로 정확, 예시 부족 또는 일부 부정확

C유형 (20점):

  • 토큰화 / 확률적 예측 / 손실함수 / 학습 데이터 각 5점
  • 4개 개념을 인과적으로 연결하면 가산, 단순 나열이면 감점

서술형 준비 방법

  1. 교재의 각 차시 핵심 정리를 다시 읽어보세요.
  2. 개념을 나만의 말과 비유로 바꿔 설명하는 연습을 하세요.
  3. C유형은 “왜?”를 반복하며 개념 간의 인과관계를 연결하는 연습이 중요합니다.
  4. 친구에게 설명해 주는 연습이 가장 효과적입니다.

7. Before/After 성찰

섹션 제목: “7. Before/After 성찰”

1차시와 9~10차시에서 같은 질문에 답합니다.

“기계가 생각할 수 있는가?”

1차시(Before)에는 여러분이 처음 든 생각을 솔직하게 적었습니다. 9~10차시(After)에는 8주간 배운 내용을 바탕으로 다시 답합니다. 두 답변의 변화를 보는 것이 이 평가의 핵심입니다.
