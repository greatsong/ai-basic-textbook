뉴런이 하는 일

맥컬록-피츠 모델의 한계

  • 입력과 출력이 0과 1만 가능
  • 자동 학습 알고리즘이 없다
  • 사람이 직접 가중치를 계산해야 함

뉴런을 수학으로 옮겼지만,
"스스로 배우는 것"과는 거리가 멀었다

15년 뒤, 1958년

프랭크 로젠블랫의 돌파

퍼셉트론(Perceptron)

맥컬록-피츠 모델 + "학습"

기계가 데이터를 보면서 스스로 가중치를 찾아가는 알고리즘

"가중치"가 뭔데?

용어 입시 비유 퍼셉트론
가중치 w 과목 반영 비율
수학 1.2배, 영어 0.8배		 입력의 영향력
편향 b 합격 커트라인 기준점 조절
활성화 합격/불합격 1 또는 0

퍼셉트론 = 직선 하나로 나누기

글자를 읽는 것보다 더 큰 의미

AND

둘 다 1일 때만 1

비밀번호 + 얼굴 인식
둘 다 맞아야 통과

OR

하나라도 1이면 1

카드 또는 현금
하나만 있으면 결제

AND + OR + NOT = 모든 논리 연산

직접 확인해봅시다

1 AND 모드에서 시작
2 w₁, w₂ 슬라이더로 직선 기울기 조절
3 b 슬라이더로 직선 위치 이동
4 4/4가 되면 성공!
5 OR 모드로 바꿔서 다시 도전

학생 교재 → "직접 확인해봅시다" 시뮬레이터

세상이 열광한 이유

퍼셉트론이 AND와 OR을 배울 수 있다면?

원리적으로 컴퓨터의 기본 연산을 배우는 기계가 가능!

글자를 읽는 것은 시작일 뿐, 가능성은 무한해 보였다

퍼셉트론 학습 규칙

"틀리면 고치고,
맞으면 냅둔다"

1이어야 하는데 0? → 가중치에 입력값을 더한다

0이어야 하는데 1? → 가중치에서 입력값을 뺀다

맞았으면? → 그대로 둔다

직접 눈으로 확인해봅시다

1 AND 모드에서 "학습 시작" 클릭
2 오른쪽 해설 패널을 주목!
3 정확도 4/4에서 자동 정지
4 OR 모드로 바꿔서 다시 학습

학생 교재 → "직접 눈으로 확인해봅시다" 시뮬레이션

오늘 배운 것

  • 퍼셉트론 = 뇌의 뉴런을 수학으로 모방한 기계
  • AND, OR 학습 성공 → 세상이 열광
  • XOR은 직선 하나로 불가능 → 수학적으로 증명됨
  • 다층으로 쌓으면 가능하지만, 학습 방법이 없었다
