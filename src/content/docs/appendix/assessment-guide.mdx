> <strong>AI 기초 수업, 어떻게 평가받게 되나요?</strong>

<p style="color: var(--sl-color-gray-3);">
이 페이지는 여러분이 수업에서 어떤 활동을 하고, 어떤 기준으로 평가받는지를 안내합니다. 미리 읽어두면 수업에 더 자신감 있게 참여할 수 있습니다.

## 1. 이 수업은 어떻게 평가되나요?

AI 기초 수업의 평가는 **시험 한 번으로 끝나지 않습니다.** 수업에 참여하는 과정과 최종 결과를 함께 봅니다.

```
총점 100점
├── 수업 중 평가 (과정) ····· 40점
└── 수업 후 평가 (결과) ····· 60점
```

| 구분 | 항목 | 배점 | 언제? |
|------|------|:----:|-------|
| **수업 중 (40점)** | 수업 참여도 (교사 관찰) | 20점 | 매 차시 |
| | 포트폴리오 (활동 기록 모음) | 10점 | 매 차시 |
| | 동료 평가 (모둠 활동) | 10점 | 9~10차시 |
| **수업 후 (60점)** | 형성평가 (활동 완수) | 10점 | 2~8차시 |
| | 서술형 평가 | 40점 | 10차시 이후 |
| | Before/After 성찰 | 10점 | 1차시 + 9~10차시 |

:::tip[핵심 메시지]
수업 시간에 성실하게 참여하고, 활동 기록을 잘 모아두는 것이 좋은 평가의 시작입니다.
:::

## 2. 수업 중 평가 (40점)

### 수업 참여도 — 교사 관찰 (20점)

선생님이 매 차시 여러분의 활동을 관찰하고 기록합니다. 10차시 동안 모든 학생을 최소 3회 이상 관찰합니다.

| 수준 | 이런 모습이면 해당됩니다 |
|------|----------------------|
| **탁월** (5점) | 적극 참여 + 창의적 기여 (새로운 질문 제기, 친구 학습 도움, 독창적 시도) |
| **우수** (4점) | 적극 참여 (활동 완수, 토의에서 의견 제시, 질문에 대답 시도) |
| **보통** (3점) | 기본 참여 (활동은 수행하나 발언이 적음) |
| **미흡** (2점) | 소극적 참여 (집중도 낮음, 토의 불참) |
| **부족** (1점) | 참여 거부 또는 방해 |

:::note[이렇게 하면 좋아요]
- 시뮬레이터 활동에서 **다양한 전략을 시도**해 보세요.
- 모둠 토의에서 **자기 생각을 한 마디라도** 말해 보세요.
- 궁금한 점이 있으면 **질문을 던져** 보세요. 질문도 훌륭한 참여입니다!
:::

### 포트폴리오 — 활동 기록 모음 (10점)

**포트폴리오에 대해서는 아래 [3. 나의 포트폴리오](#3-나의-포트폴리오) 섹션**에서 자세히 안내합니다.

### 동료 평가 — 모둠 활동 상호 평가 (10점)

**동료 평가에 대해서는 아래 [5. 동료 평가](#5-동료-평가) 섹션**에서 자세히 안내합니다.

## 3. 나의 포트폴리오

매 차시 활동한 기록을 모아두면 포트폴리오가 됩니다. 10차시가 끝난 뒤 제출합니다.

### 차시별 수집할 산출물

| 차시 | 수집할 것 | 형태 |
|:----:|----------|:----:|
| 1 | 구글 설문 성찰 기록 (Before) | 디지털 |
| 2 | XOR 실험 캡처 + 가설 메모 | 디지털/수기 |
| 3 | 활성화함수 4종 비교 기록 | 수기 |
| 4 | MSE 손계산 워크시트 | 수기 |
| 5 | 레이싱 전략 기록 (1차 vs 2~3차 비교) | 수기/디지털 |
| 6 | 순전파 계산 워크시트 | 수기 |
| 7 | 토큰화 실험 + 임베딩 탐험 기록 | 디지털 |
| 8 | Temperature 실험 + 환각 사례 기록 | 디지털 |
| 9 | 논문 카드 탐구 기록 / AI 사례 조사 워크시트 | 수기/디지털 |
| 10 | AI 한계 실험 기록 + After 성찰 | 수기/디지털 |

### 포트폴리오 평가 기준

| 수준 | 점수 | 기준 |
|:----:|:----:|------|
| 상 | 9~10 | 8개 이상 산출물 제출, 기록이 구체적이고 사고 과정이 드러남 |
| 중 | 6~8 | 5~7개 산출물 제출, 기록이 있으나 깊이가 부족한 항목 존재 |
| 하 | 3~5 | 3~4개 산출물 제출, 또는 형식적 기록 |
| 미달 | 0~2 | 2개 이하 제출 |

:::tip[포트폴리오 관리 팁]
- 수업이 끝나면 **바로 정리**하는 습관을 들이세요. 나중에 모으려면 잊어버립니다.
- 디지털 자료는 **스크린샷을 찍어** 폴더에 저장해 두세요.
- 수기 자료는 **파일이나 클리어파일**에 차시별로 모아두세요.
:::

## 4. 자기 평가 체크리스트

자기 평가는 성적에 직접 반영되지 않지만, **스스로 돌아보는 힘(메타인지)**을 기르는 데 도움이 됩니다. 매 차시 종료 2분 전에 체크합니다.

### 매 차시 공통 점검 항목

| 항목 | 5 | 4 | 3 | 2 | 1 |
|------|:-:|:-:|:-:|:-:|:-:|
| 오늘 활동에 적극적으로 참여했다 | | | | | |
| 오늘 배운 핵심 개념을 한 문장으로 말할 수 있다 | | | | | |
| 궁금한 점이 생겼거나 새롭게 알게 된 것이 있다 | | | | | |

그리고 한 줄 메타인지 기록을 남깁니다.

> "오늘 수업에서 가장 '아하!'했던 순간은? ________________"

### 차시별 자기 점검 포인트

| 차시 | 스스로 물어보세요 |
|:----:|----------------|
| 1 | "기계가 생각할 수 있는가?"에 대해 나름의 답을 적었는가? |
| 2 | XOR이 왜 안 되는지 나만의 말로 설명할 수 있는가? |
| 3 | 활성화함수를 켜고 끈 차이를 관찰하고 기록했는가? |
| 4 | MSE 계산을 직접 해보고, 손실이 줄어드는 느낌을 체험했는가? |
| 5 | 레이싱에서 1차와 2~3차 전략이 어떻게 달라졌는지 기록했는가? |
| 6 | 순전파 4단계 계산을 (도움 받더라도) 끝까지 완수했는가? |
| 7 | 토큰화 실험에 참여하고, 임베딩 갤럭시에서 패턴을 발견했는가? |
| 8 | Temperature를 바꿔보고, 환각이 왜 발생하는지 이유를 적었는가? |
| 9 | AI 활용 사례를 조사하고, 내 진로와 연결해 생각해 보았는가? |
| 10 | AI의 한계를 직접 실험하고, 구조적 원인을 분석해 보았는가? |

## 5. 동료 평가

9차시와 10차시의 모둠 활동이 끝난 뒤, 같은 모둠 친구들을 서로 평가합니다. **자신은 평가하지 않습니다.**

### 평가 항목 (5단계 척도)

| 평가 항목 | 5 | 4 | 3 | 2 | 1 |
|----------|:-:|:-:|:-:|:-:|:-:|
| **역할 수행**: 맡은 역할을 책임감 있게 수행했다 | | | | | |
| **의견 제시**: 구체적 근거를 들어 의견을 말했다 | | | | | |
| **경청 및 보완**: 다른 사람의 의견을 듣고 보완했다 | | | | | |
| **개념 활용**: 수업에서 배운 개념을 토의에 활용했다 | | | | | |

### 동료 평가 규칙

- **익명**으로 진행합니다 (선생님만 확인합니다).
- 모둠원에게 받은 점수의 **평균**이 여러분의 동료 평가 점수가 됩니다.
- 전원 5점 또는 전원 1점처럼 **극단적 점수**를 주면 선생님이 교차 확인합니다.
- **솔직하고 공정하게** 평가해 주세요. 친해서 높은 점수, 서먹해서 낮은 점수는 안 됩니다.

| 동료 평가 평균 | 환산 점수 (10점 만점) |
|:-------------:|:-------------------:|
| 4.5 이상 | 10 |
| 4.0~4.4 | 9 |
| 3.5~3.9 | 8 |
| 3.0~3.4 | 7 |
| 2.5~2.9 | 6 |
| 2.0~2.4 | 5 |
| 2.0 미만 | 4 이하 |

## 6. 서술형 평가 안내

10차시 수업이 모두 끝난 뒤, **손글씨로** 서술형 평가를 봅니다. 문항은 **사전에 공개**되므로 미리 준비할 수 있습니다.

### 문항 구조

<CardGrid>
  <Card title="A유형 — 개념 설명 (4문항)">
    "~의 역할을 설명하시오", "~의 특징을 비교하시오"처럼 **핵심 개념을 정확하게 서술**하는 문항입니다.

    - A1: 활성화함수의 역할 + ReLU vs Sigmoid 비교
    - A2: 손실함수의 역할 (학습과 최적화의 관계)
    - A3: 경사하강법의 원리 (기울기, 학습률, 최솟값)
    - A4: 활성화함수 3종 이상 + 각 특징
  </Card>
  <Card title="B유형 — 상황 적용 (2문항)">
    "만약 ~라면 어떻게 되는가?"처럼 **배운 개념을 새로운 상황에 적용**하는 문항입니다.

    - B1: 단층 퍼셉트론이 XOR을 못 푸는 이유 (좌표평면 활용)
    - B2: 활성화함수를 전부 제거하면 생기는 문제 (XOR 예시)
  </Card>
  <Card title="C유형 — 종합 분석 (1문항)">
    여러 개념을 **인과적으로 연결**하여 분석하는 문항입니다.

    - C1: ChatGPT가 환각을 일으키는 구조적 원인
    - (토큰화, 확률적 예측, 손실함수, 학습 데이터를 연결하여 설명)
  </Card>
</CardGrid>

### 배점과 환산

- 7문항의 원배점 합계는 **80점**입니다.
- 원점수에 **0.5를 곱해** 40점 만점으로 환산합니다.
- 예: 원점수 64점이면 → 64 x 0.5 = **32점**

### 채점 기준 요약

**A/B유형 (각 10점):**

| 수준 | 점수 | 기준 |
|:----:|:----:|------|
| 상 | 9~10 | 핵심 개념 정확 + 구체적 예시나 비유 포함 |
| 중 | 6~8 | 대체로 정확, 예시 부족 또는 일부 부정확 |
| 하 | 3~5 | 일부 개념만 서술, 불완전 |
| 미달 | 0~2 | 이해 부족 또는 무관한 내용 |

**C유형 (20점):**
- 토큰화 / 확률적 예측 / 손실함수 / 학습 데이터 **각 5점**
- 4개 개념을 **인과적으로 연결**하면 가산, 단순 나열이면 감점

:::tip[서술형 준비 방법]
1. 교재의 **각 차시 핵심 정리**를 다시 읽어보세요.
2. 개념을 **나만의 말과 비유**로 바꿔 설명하는 연습을 하세요.
3. C유형은 "왜?"를 반복하며 **개념 간의 인과관계**를 연결하는 연습이 중요합니다.
4. 친구에게 **설명해 주는 연습**이 가장 효과적입니다.
:::

## 7. Before/After 성찰

1차시와 9~10차시에서 **같은 질문**에 답합니다.

> "기계가 생각할 수 있는가?"

1차시(Before)에는 여러분이 처음 든 생각을 솔직하게 적었습니다. 9~10차시(After)에는 8주간 배운 내용을 바탕으로 다시 답합니다. 두 답변의 **변화**를 보는 것이 이 평가의 핵심입니다.

### 평가 항목

| 항목 | 배점 | 이런 답변이면 좋습니다 |
|------|:----:|---------------------|
| 1차시 답변 회고 | 2점 | 과거 내 답변의 논리와 근거를 구체적으로 되짚음 |
| 10차시 답변의 깊이 | 4점 | 수업에서 배운 개념 3개 이상을 인과적으로 연결하여 답변 |
| 변화 인식 | 2점 | "왜 생각이 바뀌었는지(또는 유지되었는지)" 원인을 분석 |
| 성찰의 진정성 | 2점 | 남의 말을 베끼지 않고, 자기 언어로 솔직하게 서술 |

:::note[Before/After 성찰 팁]
- "생각이 바뀌었다"가 정답이 아닙니다. 바뀌지 않았더라도 **그 이유를 논리적으로 설명**하면 좋은 점수를 받습니다.
- 1차시에 적은 답변을 기억해 두세요. 비교가 구체적일수록 좋습니다.
- 수업에서 배운 **개념 이름**(퍼셉트론, 손실함수, 임베딩, 어텐션 등)을 활용하면 깊이가 달라집니다.
:::

## 8. 성적 산출

최종 성적은 아래와 같이 계산됩니다.

### 총점 구성

```
총점 = 수업 중 평가(40점) + 수업 후 평가(60점) = 100점

수업 중 평가 40점
  ├── 교사 관찰 ········ 20점 (관찰 차시 평균 → 환산)
  ├── 포트폴리오 ······· 10점 (산출물 수 + 질적 수준)
  └── 동료 평가 ········ 10점 (동료 평가 평균 → 환산)

수업 후 평가 60점
  ├── 형성평가 ·········· 10점 (2~8차시 활동 완수 수)
  ├── 서술형 평가 ······· 40점 (원점수 80점 × 0.5)
  └── Before/After ····· 10점 (4개 항목 합산)
```

### 등급 기준

| 등급 | 점수 범위 | 의미 |
|:----:|:---------:|------|
| **A** | 85~100점 | 핵심 개념을 정확히 이해하고 인과적으로 연결하여 설명 가능 |
| **B** | 70~84점 | 핵심 개념을 이해하고 부분적으로 적용 가능 |
| **C** | 55~69점 | 기본 개념을 이해하나 적용에 어려움 |
| **D** | 40~54점 | 일부 개념을 이해하나 설명이 불완전 |
| **E** | 0~39점 | 핵심 개념의 이해가 부족 |

### 이런 학생은 어떤 등급일까요?

<CardGrid>
  <Card title="A등급 예시 (95점)">
    - 교사 관찰 평균 4.5 → **20점**
    - 포트폴리오 9개 제출 + 구체적 기록 → **10점**
    - 동료 평가 평균 4.3 → **9점**
    - 형성평가 7개 완수 → **10점**
    - 서술형 원점수 74/80 → **37점**
    - Before/After → **9점**
  </Card>
  <Card title="C등급 예시 (60점)">
    - 교사 관찰 평균 3.2 → **14점**
    - 포트폴리오 5개 제출 → **6점**
    - 동료 평가 평균 3.0 → **7점**
    - 형성평가 4개 완수 → **7점**
    - 서술형 원점수 42/80 → **21점**
